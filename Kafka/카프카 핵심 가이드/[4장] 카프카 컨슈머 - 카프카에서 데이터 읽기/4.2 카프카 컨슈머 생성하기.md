# 4.2 카프카 컨슈머 생성하기 (p90)

1. KafkaConsumer 인스턴스 생성
 - ex. KafkaProducer 인스턴스 생성하는 것과 매우 비슷한데, 컨슈머에 넘겨주고 하는 설정을 담은 Java Properties 객체를 생성하면 됨.

2. 설정 값
 - `bootstrap.servers` : 카프카 클러스터로의 연결 문자열
 - `key.deserializer` : 바이트 배열을 자바 객체로 변환하는 클래스 지정
 - `value.deserializer` : 바이트 배열을 자바 객체로 변환하는 클래스 지정
 - `group.id` : KafkaConsumer 인스턴스가 속하는 컨슈머 그룹을 지정
