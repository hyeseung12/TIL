# 7.1 신뢰성 보장 (p183)

- 보장이란? 서로 다른 상황에서도 시스템이 지킬 것이라 보장되는 행동을 의미한다.

- 가장 잘 알려진 표준 신뢰성 보장은 ACID -> 트랜잭션 처리 관련해서 어떠한 행동을 보장한다.
  - A : 원자성
  - C : 일관성
  - I : 격리성
  - D : 지속성

- 아프카 카프카는 다음을 보장한다.
  - 파티션 안의 메시지들 간 순서를 보장한다.
  - 클라이언트가 쓴 메시지는 모든 ISR의 파티션에 쓰여진 뒤에야 '커밋'된 것으로 간주된다.
    - 프로듀서는 메시지가 완전히 커밋된 다음 응답이 올지, 리더에게 쓰여진 다음 응답이 올지 아니면 네트워크로 전송된 다음 바로 응답이 올지를 선택 가능하다.
  - 커밋된 메시지들은 최소 1개의 작동 가능한 레플리카가 남아 있는 한 유실 되지 않는다.
  - 컨슈머는 커밋된 메시지만 읽을 수 있다.

- 트레이드 오프는 대개 메시지를 저장하는 데 있어서의 신뢰성과 일관성이 우선이냐 vs
  가용성이나 높은 처리량, 낮은 지연, 하드웨어 비용과 같이 다른 고려사항이 우선이냐에 문제인 경우가 많다.
